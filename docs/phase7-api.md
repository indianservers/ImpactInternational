# Phase 7 finance API

Finance routes reuse authenticated workspace permissions, explicit entity grants, CSRF protection for mutations, bounded pagination and the existing error format. The signed webhook is the only anonymous finance mutation and is exempt from CSRF; it verifies the raw-body signature and provider state.
